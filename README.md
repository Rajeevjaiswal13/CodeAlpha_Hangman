# CodeAlpha Hangman Game 🎮

## Project Overview

This project is a simple, text-based Hangman game developed using Python as part of my CodeAlpha internship.

The player must guess a hidden word by entering one letter at a time. The player has a maximum of six incorrect guesses to find the correct word.

## Features

* Random word selection from five predefined words.
* Letter-by-letter guessing.
* Maximum of six incorrect guesses.
* Display of correctly guessed letters.
* Input validation.
* Detection of repeated guesses.
* Winning and losing messages.

## Technologies Used

* Python 3
* Random module
* While loop
* If-else statements
* Lists and strings
* User input and console output

## How to Run the Project

### Prerequisites

Install Python 3 on your computer.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/Rajeevjaiswal13/CodeAlpha_Hangman.git
   ```

2. Open the project folder:

   ```bash
   cd CodeAlpha_Hangman
   ```

3. Run the game:

   ```bash
   python hangman.py
   ```

   On Windows, you can also use:

   ```bash
   py hangman.py
   ```

## How to Play

1. Run the Python program.
2. The game selects a random word.
3. Enter one alphabet letter when prompted.
4. Correct guesses reveal letters in the hidden word.
5. Incorrect guesses reduce the remaining attempts.
6. Guess the word before using all six incorrect guesses to win.
